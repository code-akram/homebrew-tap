# code-akram/homebrew-tap

Homebrew formulas for code-akram projects.

```sh
brew install code-akram/tap/cc-fm
brew services start cc-fm    # optional: keep the player running at login
```

Homebrew 6 and later only load formulae from third-party taps you trust. Installing by full name (`code-akram/tap/cc-fm`) trusts that one formula. If Homebrew reports it's ignoring formulae from this tap, run `brew trust --formula code-akram/tap/cc-fm` (or `brew trust --tap code-akram/tap` for all of them).

| Formula | Project |
|---|---|
| `cc-fm` | [cc-fm-mod](https://github.com/code-akram/cc-fm-mod): claude.fm with a live spectrum in Claude Code |

Formulas are updated automatically by each project's release workflow.
